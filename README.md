# آستان جانان — Android MVP

پروژه‌ی پایه‌ی اندروید با Kotlin، Jetpack Compose و رابط فارسی RTL.

## ساخت APK در GitHub
1. فایل `astan-janan-source-full.zip` را استخراج کنید (یا هر چهار فایل part را در یک پوشه‌ی مشترک استخراج کنید).
2. محتویات پروژه را در ریشه‌ی یک GitHub repository قرار دهید.
3. در GitHub وارد تب **Actions** شوید.
4. Workflow با نام **Build Android APK** را اجرا کنید.
5. پس از پایان موفق، از بخش **Artifacts** فایل `astan-janan-debug-apk` را دانلود کنید.
6. فایل APK داخل Artifact را روی گوشی نصب کنید. برای نصب خارج از Play Store ممکن است لازم باشد اجازه‌ی نصب از منبع مربوطه را فعال کنید.

## ساخت محلی
- JDK 17 و Android SDK نصب باشد.
- Android Studio پروژه را باز کند و Gradle Sync انجام شود.
- دستور ساخت: `gradle --no-daemon assembleDebug`
- مسیر خروجی: `app/build/outputs/apk/debug/app-debug.apk`

## مواردی که هنوز پیاده‌سازی نشده‌اند
این نسخه MVP است، نه نسخه‌ی کامل نهایی. متن قرآن و ترجمه‌ی آفلاین، بانک حدیث و دعا، Room و ذخیره‌سازی دائمی، اوقات شرعی، قبله، اعلان‌ها، جست‌وجوی سراسری و دستیار هوشمند هنوز اضافه نشده‌اند. برای جلوگیری از انتشار محتوای نادرست، متن آیات یا احادیث نمونه و ساختگی درج نشده است.
